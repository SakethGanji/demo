# Engine app-builder cleanup review (read-only)

1. Scope: ~19.3K lines core (app_*.py 7.1K, app_kit 4.4K, oneshot 2.3K, build_coordinator 1.5K, selftest/platform_index/tsx_parser/scanners/routes/schemas); ~31.7K if module_generator, builder_gates, project_plan/files/knowledge, plan_*, backend_templates are counted.
2. Safely removable (high/med-high confidence): ~6,100 lines of engine python/mjs/tsx, plus ~5K lines of tests that pin the removed code. A further ~1,600 (AI app composer) + ~1,260 studio lines and ~380 (scenario autotest) are decisions, not safe cuts.
3. TOP 1 (~1,850 lines, high): drop the visual-editing trial residue. editability_lint.py, editability/*.mjs, overlay/display/board/plots kit files, registry/repair code in oneshot_builder, WORKFLOW_EDITABLE_RULES branches. The lint (a node subprocess, 30 s timeout) runs on EVERY build even with the flag off, and its result is read by nobody.
4. TOP 2 (~3,050, med-high): delete the agent loop (`_run_agent_loop`, tools, clarify/brief, StallGuard, lookups) in app_builder_ai_service.py, plus app_scaffold.py. Route every chat to oneshot (write if the app is empty, else edit_app). Today the same chat box has two builders depending on a hidden `studio.oneshot` flag.
5. TOP 3 (~1,200, high): delete the WORKFLOW_BUILDER_MODE=pipeline path. Roughly 800 lines of build_coordinator.py (Builders, fast-path modules, input step, verify) and backend_templates/scaffold.py.
6. TOP 4 (BUG, small diff, highest impact): a single-module plan whose output exceeds MAX_OUTPUT_TOKENS (20,000, non-streaming) cannot fall back to splitting (`features()` returns [] for <2 modules), so the build hard-fails with WriteError. Replace the two split strategies with the existing `_write_staged` (backend, then screens in parallel) as the one fallback, and stream the call.
7. TOP 5 (~270, med): collapse the compact profile, no-tools JSON mode, split-by-feature writer, and the 2-pass fix to a single profile with ONE fix pass. Today "at most 1 fix" is really up to 1 fix plus 3 `read_files` rounds plus 1 edit-correction round per fix, and 2 passes on small-model names.
8. Footgun: `check_app_files` and `typecheck_errors` gate the TypeScript type-check on `clarify_enabled()` (WORKFLOW_APP_BUILDER_CLARIFY). Turning clarify off while simplifying silently disables tsc for all builds.
9. Perf/storage: every app version saves all ~4.4K lines of kit files into the DB, and `FileStorage.save_files` tree-sitter-parses and API-scans each of them on every save. Skip kit/ (store once).
10. Environment coupling: tsc, publish-time Tailwind and the babel parser all resolve `../workflow-studio/node_modules` by relative path; a missing esbuild makes `_generated_syntax_errors` return an error string that feeds the fix pass.

Line counts are approximate. Paths are relative to /home/saketh/Projects/playground/work/demo/apps/workflow-engine/src unless noted. "Studio calls" = checked in apps/workflow-studio/src (excluding features/app-builder/visual).
