Persisted vs ad-hoc
↳ Persisted. POST …/versions/{n}/profile-runs — scoped to sheet + version, gets a run_id, appears above, and is what an insight cites. Versions are immutable, so a run never goes stale.
↳ Ad-hoc. POST /datasets/{id}/profile — same shape, then persists nothing: no run_id, no history, nothing to link back to. Fine for a look; useless as evidence.
