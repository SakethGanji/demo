Connection
The prefix namespaces this server's tools so two connectors cannot collide. Empty is allowed only because this is the first connector — names are pinned on import and never renamed by a re-discovery.
Identity
This server authenticates by header, not by token. Whose identity does a tool call carry?
If a run has no acting user, this connector contributes zero tools and logs an error. It never falls back to a default seat — a silently-anonymous call against a header-auth service returns a 200 with somebody else's scope.
