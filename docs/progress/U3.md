## Deviations and notes

- **No backend change.**
- **`unmasked_refused` rendering is not exercised live.** The UI greys Unmask for anyone `/authz/check` refuses, so a refused read only reaches the API when the check is stale. The alert is the same path U2 exercised with a stubbed check.
- **Retention periods typed in the card apply to one plan only.** They are sent as `periods` and recorded with the dry run. Changing the team policy itself stays in Settings › Teams › Policy (the U2 JSON editor, owners).
- **Delete requests made by a retention run** are decided where delete requests already are: the dataset page, or by API in the walk. The card says so.
- **Disabled-button CSS** is a shared change (3 lines in `primitives.css`). It makes every page's greyed buttons visibly grey. Before, `disabled` buttons looked live everywhere.
- **The ops mapping is shown as typed.** The API upper-cases the keys.
- **Clean-up:** the scratch data dir, venv, API and Vite processes were in the scratchpad and are stopped. Nothing was left in the repository apart from this report, the scripts, `calls.txt`, `setup_output.txt` and the screenshots.
