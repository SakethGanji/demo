# Engine platform review (everything in apps/workflow-engine/src except app-builder services)

Method: read the code (runner, repos, routes, cron/reaper, seed, Code node, files route, ai_agent loop, models, main), counted importers with a script (`imp.py`, `imp2.py` in this folder), and matched every engine route against the studio call sites (`shared/api/endpoints.ts`, `shared/lib/api.ts`, `features/*/api*.ts`, plus grep of the whole studio src). Engine tests were not counted as "callers".

## Summary (10 lines)

1. Lines in scope: about 88,800 of 100,200 Python lines under src (nodes 17.4k, engine 9.3k, routes 7.0k, repositories 3.6k, db 3.1k, schemas 2.1k, broker+sdk 2.4k, services about 36k).
2. Safely removable now (dead, or reachable only from a dropped/unused surface, confidence 0.8 or better): about 9,000 lines (about 9% of scope).
3. Removable with a product decision (0.4 to 0.7 confidence, needs studio edits): a further 17,000 to 20,000 lines (KG, workflow-AI-builder pipeline, interfaces, QA extras, jobs, Mongo/Neo4j).
4. Top 5 actions, ranked by lines x confidence:
5. (1) Agent memory (11 classes) + 13 agent tools nobody selects + their util: about 4,400 lines, 0.9. Zero templates, zero tests, zero studio references.
6. (2) Dead-product bundle: n8n import (1.2k), PromptLab seed + Mongo index bootstrap (1.0k), credentials stack (0.4k), folders (0.2k), `schema_analyzer.py` (0.23k), dead tables: about 3,100 lines, 0.9. No studio caller / no importer.
7. (3) Collapse the workflow AI builder (proposal/spec/question/round pipeline, 8.1k lines) to one LLM call plus the existing checker gate: about 6k saved, 0.35. This is the same "role-split pipeline" the owner already replaced for apps.
8. (4) Remove the hand-rolled "capability graph" NLU (kg_*, 4.4k lines + studio 3D page 7.2k TS lines): about 4.4k, 0.5. It only feeds the AI builder's Understand step.
9. (5) Cut QA extras no business user needs (fuzz, mutations, scorecard, AI-drafted tests, drift, smoke, plus 6 routes): about 3,100 lines, 0.5. Also fix 5 real bugs listed below (in-process `exec` fallback, cron double-fire, unauthenticated filesystem browse, SSRF check, runner cleanup).
