# Studio cleanup review: workflow-editor, small features, shared, app

Scope: apps/workflow-studio/src (paths below are relative to it). READ-ONLY review; nothing in the repo was touched.

## Summary
1. Total lines in scope: ~58.4k including tests (editor 25.4k, shared 12.1k, backend 6.5k, data 3.7k, interfaces 2.4k, runs 2.1k, settings 1.8k, releases 1.4k, app 1.2k, secrets 1.1k, datasets 0.8k, workflows-list 0.1k).
2. An import-graph walk from app/main.tsx (tests excluded) found only 3 unreachable files in scope: ai-elements/task.tsx, ai-elements/tool.tsx, workflows-list/workflowMeta.ts. The code is mostly wired in. The bloat is dead exports inside live files, vendored UI kits, and whole sub-products.
3. Lines safely removable now (high confidence, no behaviour or look change): ~1,750.
4. Lines removable if the owner cuts sub-features (decision, not dead code): ~6-7k more (editor Tests feature ~2.8k, editor/interfaces Interface+AskBar stack, release/environment stack, design.tsx 536).
5. Top 5 by lines x confidence: (A) trim vendored ai-elements/prompt-input.tsx, message.tsx, code-block.tsx, conversation.tsx and file-tree.tsx, plus delete task.tsx and tool.tsx, ~1,250 lines, high; (B) delete the dead functions in the editor (useExecuteWorkflow, usePublishWithImpact, test and stage helpers), ~250, high; (C) cut or park the editor Tests sub-product (fuzz, smoke, drift, AI drafts, scorecard), ~2.8k, medium (owner call); (D) remove the dev-only app/routes/design.tsx, 536, medium-high; (E) merge RunInline and RunSheet, and the two trace renderers (backend TraceView vs runs TraceWaterfall), ~400, medium.
6. Next: unused api.ts and endpoints.ts members (14, ~70 lines, high), orphaned shadcn sidebar and chart CSS tokens (~45 lines, medium-high), floatingSheetCls living in settings (a move, not a removal).
7. Not worth touching: ui primitives (all have 2+ users), table and empty-state (already consolidated: 31 EmptyState users, one Table primitive), liquid-glass, specular and starfield (they are the look), data vs datasets (different concepts).
8. Tests that cover only removed code (e.g. stageGeometry.test.ts partial, tests.test.ts helpers) must be trimmed with it.
9. The bundler (not me) should confirm each removal with `tsc -b` and `npm run test:ui`. Every "unused" claim below was checked by grepping non-test source for the name (word match).
10. All line numbers are from the current working tree (dirty branch revert-to-5684ba5).
